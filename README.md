# Lunar Link organization website

This repository publishes the Lunar Link project overview at [lunar-link.github.io](https://lunar-link.github.io/).

The site source is in [`site/`](site/). A GitHub Actions workflow publishes it to GitHub Pages when `site/` or the workflow changes on `main`.

The mesh network firmware and technical documentation live in [Lunar-Link/mesh-network](https://github.com/Lunar-Link/mesh-network).
